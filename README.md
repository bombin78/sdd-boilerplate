# SDD-бойлерплейт для проектов с Claude Code

Заготовка для проекта, который ведётся по SDD: сначала задача и её
условия приёмки пишутся в файл, потом по ним пишется код. Код пишет
Claude Code, задачи принимает пользователь.

Здесь нет кода приложения. Есть только то, что не меняется от проекта
к проекту: правила для Claude, скиллы, агент, хуки, настройки Claude Code
и болванки задач с комментариями.

Этот `README.md` в новый проект не копируется.

## Что внутри

```
├── AGENTS.md                ← формат коммитов; генератор стека может дописать своё
├── CLAUDE.md                ← подключает AGENTS.md
├── CLAUDE.local.md          ← подключает правила из notes/claude/
├── backlog.md               ← отложенные замечания, болванка пункта
├── .githooks/pre-commit     ← запрещает коммиты в main
├── .claude/
│   ├── settings.json        ← права и песочница Claude Code
│   ├── settings.local.json  ← подключает хуки из notes/hooks/
│   ├── rules/               ← ссылки на code-rules.md и stack-rules.md
│   ├── skills/              ← ссылки на скиллы /explain и /setup-project
│   └── agents/              ← ссылка на агента answer-reviewer
└── notes/                   ← отдельный закрытый git-репозиторий заметок
    ├── README.md            ← как заметки подключены к проекту
    ├── CLAUDE.md            ← правила работы с notes/
    ├── claude/              ← правила, скиллы, агент
    ├── hooks/               ← хуки: защита заметок, запрет записи в git
    ├── docs/, ideas/        ← разборы тем и идеи, пока пустые
    └── tasks/               ← задачи: правила, списки, болванки
```

Подробно о каждом файле в `.claude/` и о том, когда Claude Code его
загружает, — в `notes/README.md`.

## Как начать новый проект

**1. Создать проект.** Если у стека есть генератор, запустить его
первым: он создаёт папки кода, `package.json` и иногда свои `AGENTS.md`
и `CLAUDE.md`.

```bash
npx create-next-app@latest my-app   # пример для Next.js
cd my-app
```

Если генератора нет, создать пустую папку и `git init` в ней.

**2. Скопировать бойлерплейт.** Из папки нового проекта:

```bash
rsync -a --ignore-existing --exclude /.git --exclude /README.md ~/dev/sdd-boilerplate/ ./
```

- `-a` — копирует вместе с символическими ссылками и правами файлов;
- `--ignore-existing` — не трогает файлы, которые уже создал генератор;
- `--exclude /.git`, `--exclude /README.md` — не копирует git
  бойлерплейта и этот файл. Слеш в начале значит «только в корне»:
  `notes/README.md` копируется.

Если генератор уже создал `AGENTS.md`, допишите в его конец раздел
«Commit messages» из `AGENTS.md` бойлерплейта.

**3. Дописать `.gitignore` проекта.** Строки — в `notes/README.md`,
раздел «Строки в `.gitignore` проекта».

**4. Включить хук `pre-commit`:**

```bash
git config core.hooksPath .githooks
```

**5. Сделать `notes/` отдельным репозиторием:**

```bash
cd notes
git init
git remote add origin <адрес закрытого репозитория заметок>
cd ..
```

Первый коммит в `notes/` делается после шага 7, когда правила заполнены.

**6. Заменить строки в угловых скобках** в `notes/README.md`: имя
проекта и адреса репозиториев.

**7. Настроить под проект и под себя:**

```bash
claude
```

В сессии запустить `/setup-project`. Скилл:

- определяет стек по файлам проекта, а в пустом проекте задаёт
  вопросы о технологиях;
- заполняет `notes/claude/stack-rules.md` и шаблоны путей в
  `notes/claude/code-rules.md`;
- спрашивает, какие темы вы знаете, и заново создаёт раздел «Читатель»
  в `notes/claude/answer-rules.md`.

После этого перезапустить сессию: правила ответов загружаются при
старте.

**8. Проверить, что всё подключено.** Список проверок — в
`notes/README.md`, раздел «Как собрать всё заново», пункты 5–7.

**9. Заменить болванки своими задачами.** Примеры лежат в
`notes/tasks/registry/`, `notes/tasks/app/`, `notes/tasks/infra/`
и в `backlog.md`. Как устроены задачи — в `notes/tasks/README.md`.

## Git самого бойлерплейта

Если в глобальном `~/.config/git/ignore` есть строка
`**/.claude/settings.local.json`, git бойлерплейта этот файл пропустит.
Добавить его один раз вручную:

```bash
git add -f .claude/settings.local.json
```

`.gitignore` в бойлерплейте нет специально: строки из шага 3 нужны
новому проекту, а в git бойлерплейта должна попасть и папка `notes/`.
