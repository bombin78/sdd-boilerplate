Вопрос пользователя: $ARGUMENTS

Эта команда только читает код и отвечает. Файлы не создавай и не меняй.

## Шаги

1. Прочитай `notes/project.md`: по карте кода и сценариям найди файлы,
   которые нужны для ответа. Потом прочитай код. Если `project.md`
   расходится с кодом, верь коду, а после ответа одной строкой скажи,
   какой раздел `project.md` устарел. Если вопрос касается технологии
   стека, сверься с документацией из раздела «Документация»
   `notes/claude/stack-rules.md`.
2. Составь список терминов для ответа. Возьми раздел «Читатель» из
   `notes/claude/answer-rules.md`. Все термины из «Знаю частично» и «Не знаю»,
   которые встретятся в ответе, попадают в список. Для каждого термина
   напиши одну фразу о том, что он значит.
3. Напиши черновик по правилам из `notes/claude/answer-rules.md`. Если список
   из шага 2 не пустой, черновик начинается со списка «Термины». Дальше
   используй только слова из этого списка.
4. Вызови агента `answer-reviewer`. Передай ему вопрос пользователя и
   черновик целиком.
5. Если агент вернул нарушения, исправь каждое. Потом снова вызови агента
   с исправленным черновиком. Всего не больше двух проверок.
6. Покажи пользователю итоговый ответ.
   - Если после второй проверки нарушения остались, после ответа перечисли
     их одной строкой каждое.
   - В итоговом ответе процесс проверки не описывай. Черновик не показывай.
